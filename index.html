    How it works
    
      
      
        
    • The file is split into chunks of the chosen size (default 20 MB, safely under GitHub's ~100 MB per-file limit).
      • 
        
    • Each chunk is uploaded as its own file via the GitHub Contents API.
      • 
        
    • A manifest.json records the original name, size, chunk count and order.
      • 
        
    • You get one raw link per chunk plus a manifest link. Large downloads can be rebuilt client-side.
      • 
        
    • Chunk size is capped at 90 MB to stay below GitHub limits even after base64 encoding.
